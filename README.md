# Remix of Maury Laurent Prestige

Crée le nouveau site internet de Maury Laurent, entreprise familiale spécialisée dans la peinture, la décoration et la rénovation, située à Bouloc.

Le site doit être conçu comme un site vitrine premium haut de gamme, avec une forte dimension artisanale et familiale.

1. POSITIONNEMENT

Maury Laurent ne doit pas être présenté comme un simple peintre en bâtiment.

Le positionnement est :

Entreprise familiale de peinture, décoration et rénovation

avec une capacité à accompagner des projets de rénovation de manière globale, potentiellement de A à Z, avec un interlocuteur unique.

Le cœur de métier reste :

peinture intérieure ;

peinture décorative ;

décoration ;

conseil ;

home staging.

Les autres expertises importantes sont :

rénovation intérieure ;

parquet et revêtements de sols ;

ravalement et peinture extérieure.

L'entreprise existe depuis 1994 et s'inscrit dans une histoire familiale de quatre générations d'artisans.

Laurent travaille aujourd'hui avec son fils.

2. OBJECTIFS DU SITE

Le site doit :

donner immédiatement une impression de qualité et de sérieux ;

positionner Maury Laurent comme une entreprise premium ;

générer des demandes de devis ;

générer des appels téléphoniques ;

présenter les réalisations ;

valoriser le savoir-faire artisanal ;

mettre en avant l'expérience familiale ;

présenter clairement les différentes expertises ;

être pensé dès le départ pour le référencement local.

CTA principal :

Demander un devis

CTA secondaire :

Parler de votre projet

Le numéro de téléphone doit être très facilement accessible, notamment sur mobile.

3. DIRECTION ARTISTIQUE

Le client souhaite conserver les couleurs historiques rouge et bleu.

IMPORTANT :

Ne pas utiliser ces couleurs comme un site corporate classique ou comme un site d'artisan bas de gamme.

Créer une identité visuelle très premium, élégante et haut de gamme.

Palette

Utiliser principalement :

un bleu profond / bleu nuit comme couleur institutionnelle ;

un rouge profond et sophistiqué comme couleur d'accent ;

blanc / blanc cassé pour les fonds ;

nuances très légères de gris pour les surfaces secondaires.

Le rouge doit être utilisé avec parcimonie : CTA, détails graphiques, micro-accents, éléments importants.

Le bleu doit porter l'identité principale.

Éviter :

rouge vif omniprésent ;

bleu électrique ;

dégradés agressifs ;

ombres excessives ;

cartes génériques ;

design « artisan WordPress » ;

esthétique template ;

surcharge visuelle.

Style général

S'inspirer des codes visuels de sites de :

cabinets d'architecture ;

architectes d'intérieur ;

entreprises de rénovation haut de gamme ;

maisons de décoration ;

studios de design.

Le résultat doit être :

sobre + élégant + chaleureux + premium + intemporel.

Utiliser beaucoup d'espace blanc.

Privilégier une typographie élégante pour les grands titres et une typographie très lisible pour les textes.

Les photographies de réalisations doivent occuper une place importante dans le design.

CTA final

Présenter :

chaux ;

home staging.

Rénovation intérieure

Présenter :

rénovation globale ;

préparation des supports ;

placo ;

isolation ;

aménagement intérieur ;

cuisine ;

salle de bains ;

carrelage/faïence.

Mettre particulièrement en avant l'idée :

Un seul interlocuteur pour votre projet de rénovation.

Sols & revêtements

Présenter :

parquet ;

parquet massif ;

revêtements de sols ;

5. UX

Le parcours doit être extrêmement simple :

Je découvre → je comprends l'expertise → je vois les réalisations → je suis rassuré → je demande un devis.

Le CTA « Demander un devis » doit rester facilement accessible.

Sur mobile :

téléphone très visible ;

CTA fixe ou facilement accessible ;

navigation simple ;

formulaires courts.

6. SEO

Prévoir une structure HTML propre et SEO-friendly.

Utiliser :

H1 unique par page ;

H2/H3 structurés ;

balises title et meta description facilement modifiables ;

URLs propres ;

maillage interne ;

sitemap ;

optimisation des images ;

alt text ;

données structurées pertinentes.

Le site doit être pensé pour travailler principalement :

Bouloc + Fronton + Aucamville + Blagnac + Grenade

Ne pas créer automatiquement des dizaines de pages locales.

Prévoir plutôt une architecture permettant de développer progressivement le SEO grâce aux réalisations.

7. TON ÉDITORIAL

Le ton doit être :

professionnel ;

rassurant ;

humain ;

précis ;

premium ;

jamais commercial agressif.

Éviter les clichés du type :
« Votre projet est entre de bonnes mains ! »

Préférer un langage concret et qualitatif.

Mettre en avant le savoir-faire et les preuves plutôt que des promesses génériques.

8. IMPORTANT — CONTENU

Ne pas inventer :

avis clients ;

certifications ;

labels ;

chiffres ;

réalisations ;

photos ;

coordonnées ;

informations commerciales.

Lorsque certaines informations ne sont pas encore disponibles, utiliser des placeholders clairement identifiés.

Ne pas générer de fausses réalisations.

9. CONCEPTION

Commencer par construire une homepage très travaillée visuellement, puis décliner le système graphique sur les autres pages.

Le site doit donner dès les premières secondes une impression de :

savoir-faire artisanal + expérience + élégance + qualité + confiance.

Le résultat final doit être nettement plus haut de gamme que le site actuel et ne doit pas ressembler à un template générique d'entreprise de peinture.
